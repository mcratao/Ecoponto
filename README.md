# Ecoponto

Projeto desenvolvido para a AEP do 4º semestre do curso de  engenharia de software.

## Sobre o projeto

O **Ecoponto** é uma aplicação voltada à **ODS 12 – Consumo e Produção Responsáveis**.

O objetivo do sistema é facilitar o descarte correto de materiais recicláveis ou reutilizáveis, permitindo que o usuário encontre, de acordo com sua localização, pontos de reciclagem, estabelecimentos e eventos próximos que recebam determinados tipos de materiais.

## Problema

Muitas pessoas possuem materiais recicláveis ou reutilizáveis, mas não sabem onde realizar o descarte adequado.

A falta de informação sobre pontos de coleta pode fazer com que materiais sejam descartados de forma incorreta.

O Recicla Aqui busca centralizar essas informações e facilitar o acesso do usuário aos locais adequados para reciclagem, reutilização ou reaproveitamento.

## Principais funcionalidades

- Cadastro e login de usuários;
- Identificação da localização do usuário;
- Busca de pontos de reciclagem próximos;
- Visualização dos pontos em mapa;
- Busca por tipo de material;
- Cadastro de estabelecimentos;
- Cadastro de pontos de coleta;
- Divulgação de eventos relacionados à reciclagem;
- Visualização de informações dos estabelecimentos;
- Cálculo aproximado da distância até os pontos de coleta;
- Avaliação e comentários sobre os locais cadastrados.
