# 1. INTRODUÇÃO

O Ecoponto é uma aplicação desenvolvida com o objetivo de facilitar o descarte correto de materiais recicláveis e reutilizáveis, aproximando os usuários de locais que recebem esses materiais.

O problema identificado durante a concepção do projeto é a dificuldade que muitas pessoas encontram para descobrir onde realizar o descarte adequado de determinados resíduos. A falta de informações centralizadas pode contribuir para o descarte incorreto de materiais que poderiam ser reciclados ou reaproveitados.

Diante disso, o Ecoponto oferece uma plataforma na qual os usuários podem informar sua localização, selecionar o material que desejam destinar e encontrar pontos de coleta e eventos próximos.

O projeto está alinhado ao Objetivo de Desenvolvimento Sustentável 12 (ODS 12), da Organização das Nações Unidas, que incentiva padrões de consumo e produção responsáveis.

# 2. OBJETIVO DO SISTEMA

O principal objetivo do Ecoponto é centralizar informações sobre locais de coleta e campanhas de reciclagem, tornando mais simples o processo de identificação de destinos adequados para materiais recicláveis.

Entre os objetivos específicos estão:

- Facilitar a localização de pontos de coleta.
- Permitir a busca por materiais específicos.
- Apresentar informações sobre os locais de descarte.
- Divulgar eventos e campanhas temporárias de coleta.
- Permitir o cadastro e a manutenção de pontos de coleta.
- Contribuir para a conscientização ambiental.

# 4. FUNCIONALIDADES DO SISTEMA

## 4.1 Busca de pontos de coleta

A funcionalidade de busca permite que o usuário encontre locais de descarte próximos à sua localização.

Para realizar a pesquisa, o usuário pode utilizar sua localização ou informar manualmente as coordenadas de latitude e longitude.

Em seguida, seleciona o material que deseja destinar e define um raio máximo de busca.

O sistema utiliza essas informações como parâmetros para localizar pontos de coleta compatíveis.

## 4.2 Pontos de coleta

A seção de pontos de coleta é destinada à apresentação de locais permanentes que recebem materiais recicláveis.

Cada ponto pode conter as seguintes informações:

- Nome do estabelecimento ou local.
- Categoria.
- Endereço.
- Latitude e longitude.
- Materiais aceitos.
- Horário de funcionamento.
- Contato.
- Observações adicionais.

Essas informações permitem que o usuário identifique os locais adequados para realizar o descarte.

## 4.3 Eventos de coleta

O sistema também disponibiliza uma funcionalidade para divulgação de campanhas e eventos temporários relacionados à reciclagem.

Cada evento possui informações como:

- Nome do evento.
- Organizador.
- Endereço.
- Latitude e longitude.
- Materiais aceitos.
- Data de início.
- Data de término.
- Descrição.

Essa funcionalidade permite divulgar iniciativas de coleta que acontecem durante períodos específicos.

## 4.4 Cadastro e manutenção

O Ecoponto possui uma área destinada ao gerenciamento dos registros.

Nessa área, existem duas opções principais:

*Cadastro de ponto de coleta:* formulário destinado ao registro de novos locais permanentes, com informações de identificação, localização, materiais aceitos e contato.

*Cadastro de evento:* formulário destinado ao registro de campanhas temporárias, com informações sobre organização, localização, materiais recebidos e período de realização.

Os formulários representam a interface de gerenciamento das duas principais entidades do sistema.

# 5. REQUISITOS DO SISTEMA

Os requisitos abaixo representam as necessidades atendidas pelo escopo atual da aplicação.

## 5.1 Requisitos de funcionamento

*RF01:* O sistema deve permitir que o usuário informe sua localização por meio das coordenadas geográficas.

*RF02:* O sistema deve permitir a utilização da localização do dispositivo, quando autorizada pelo usuário.

*RF03:* O sistema deve permitir a seleção do tipo de material que o usuário deseja descartar.

*RF04:* O sistema deve permitir a definição de um raio máximo para a pesquisa de locais.

*RF05:* O sistema deve apresentar pontos de coleta compatíveis com os critérios informados na pesquisa.

*RF06:* O sistema deve permitir o cadastro de pontos de coleta com nome, categoria, endereço, coordenadas e materiais aceitos.

*RF07:* O sistema deve permitir o cadastro de eventos de coleta com nome, organizador, endereço, coordenadas, materiais aceitos e período de realização.

*RF08:* O sistema deve permitir a consulta das informações dos pontos de coleta cadastrados.

*RF09:* O sistema deve permitir a consulta das informações dos eventos cadastrados.

*RF10:* O sistema deve disponibilizar mecanismos de manutenção dos registros de pontos de coleta e eventos.

## 5.2 Requisitos não funcionais

*RNF01:* A interface deve apresentar organização visual que facilite a utilização das funcionalidades.

*RNF02:* Os formulários devem apresentar campos adequados às informações necessárias para cada cadastro.

*RNF03:* A aplicação deve permitir a utilização em navegadores modernos.

*RNF04:* As informações de localização devem utilizar coordenadas geográficas válidas.

*RNF05:* O sistema deve manter organização no código-fonte, facilitando futuras manutenções.

# 6. MODELAGEM E ORGANIZAÇÃO DOS DADOS

A aplicação possui duas entidades principais: Ponto de Coleta e Evento.

## 6.1 Entidade Ponto de Coleta

Representa um local permanente destinado ao recebimento de materiais recicláveis.

Atributos:

| Atributo | Descrição |
|---|---|
| id | Identificador do ponto. |
| nome | Nome do local. |
| categoria | Categoria do ponto. |
| endereco | Endereço completo. |
| latitude | Coordenada geográfica. |
| longitude | Coordenada geográfica. |
| materiais_aceitos | Materiais recebidos. |
| horario | Horário de funcionamento. |
| contato | Informação de contato. |
| observacoes | Informações adicionais. |

## 6.2 Entidade Evento

Representa uma campanha temporária de coleta ou iniciativa relacionada à reciclagem.

Atributos:

| Atributo | Descrição |
|---|---|
| id | Identificador do evento. |
| nome | Nome do evento. |
| organizador | Responsável pela organização. |
| endereco | Endereço de realização. |
| latitude | Coordenada geográfica. |
| longitude | Coordenada geográfica. |
| materiais_aceitos | Materiais recebidos. |
| data_inicio | Data de início. |
| data_fim | Data de encerramento. |
| descricao | Descrição do evento. |

## 6.3 Relacionamento entre as entidades

As entidades Ponto de Coleta e Evento representam tipos diferentes de locais e iniciativas disponíveis na plataforma.

Ambas possuem informações de localização e materiais aceitos, permitindo que sejam utilizadas na busca por locais próximos.

A separação entre as entidades permite organizar os dados de acordo com suas finalidades, diferenciando locais permanentes de campanhas temporárias.

# 7. OPERAÇÕES CRUD

O gerenciamento das informações do Ecoponto utiliza o conceito de CRUD, composto pelas operações Create, Read, Update e Delete.

Essas operações são aplicadas às entidades principais do sistema.

| Operação | Ponto de coleta | Evento |
|---|---|---|
| Create | Cadastrar novo ponto. | Cadastrar novo evento. |
| Read | Consultar pontos cadastrados. | Consultar eventos cadastrados. |
| Update | Alterar informações do ponto. | Alterar informações do evento. |
| Delete | Excluir ponto cadastrado. | Excluir evento cadastrado. |

O objetivo dessas operações é permitir o gerenciamento completo das informações utilizadas pela aplicação.
